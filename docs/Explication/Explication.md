# Le menu matériel et définition

Le **menu matériel et définition** sert à regrouper les différentes informations techniques et explications utiles à la compréhension de l'impression 3D. Il permet d'accéder rapidement aux différentes ressources sans avoir à les intégrer directement dans les pages de documentation des projets.

Il est composé de plusieurs catégories :

* **Définitions** : cette partie permet d'expliquer les différents termes techniques utilisés tout au long de la documentation. Elle sert notamment à comprendre le vocabulaire lié à l'impression 3D et aux projets réalisés pendant le stage.
* **Les différents types d'imprimantes** : cette section présente les différents modèles et types d'imprimantes 3D disponibles au Makerspace, ainsi que leurs particularités et leurs utilisations.
* **Les types de plastiques** : cette partie explique les différents matériaux pouvant être utilisés pour réaliser les impressions 3D. Elle permet de comprendre les caractéristiques des plastiques et de savoir dans quelles situations ils peuvent être utilisés.

L'objectif de ce menu est donc de **centraliser les informations générales** afin qu'elles restent facilement accessibles. Lorsqu'un terme, une imprimante ou un matériau est mentionné dans une page de projet, il est possible de consulter cette section pour obtenir davantage d'informations. Les mots de définitons possèdent normalement une balise qui une fois clické ramène vers la page de définition. 

Cela permet également d'éviter de répéter les mêmes explications dans plusieurs pages et de rendre le site **plus clair, organisé et facile à consulter**.
